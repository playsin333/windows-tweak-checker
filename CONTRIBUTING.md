# Как помочь

Лучшая помощь чекеру — отчёты с настоящих компьютеров.

**Ложное срабатывание.** Если на Windows, которую никто не трогал, чекер нашёл твик, [открой issue](https://github.com/playsin333/windows-tweak-checker/issues/new?template=false-positive.yml) и приложи отчёт с рабочего стола. По нему я поправлю стоковое значение.

**Новая проверка.** Знаешь оптимизатор или твик, который чекер не видит? [Предложи проверку](https://github.com/playsin333/windows-tweak-checker/issues/new?template=new-check.yml): что меняется, где в реестре и какие следы остаются.

**Код.** Пул-реквесты приветствуются. Пара правил, чтобы ничего не сломать:

- Чекер только читает. Никаких `Set-*`, `New-ItemProperty`, `sc config`, `reg add` и прочих записей. Это главное обещание проекта.
- Код должен работать в Windows PowerShell 5.1: без `??`, тернарного оператора и `&&` между командами.
- Батник хранится с переводами строк CRLF и в UTF-8 без BOM. Если редактор сохранит иначе, cmd может сломаться.
- Стоковое значение добавляй только если проверил его на чистой Windows 10 и 11.
- У каждой проверки должна быть оценка (польза, плацебо, спорно, вред, опасно) и причина одной строкой. Пользу и вред ставь только там, где это подтверждено замерами, иначе спорно.

Каждый пуш автоматически прогоняется на Windows в GitHub Actions.

**Новая версия.** Поменяй `$TcVersion` в батнике и добавь раздел `## [версия]` в CHANGELOG.md. После пуша в main релиз с архивом соберётся сам.
